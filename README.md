# Arık Yapı — Demo Web Sitesi

Responsive, tek sayfalı kurumsal demo. Navigasyon kullanıcının istediği sıralamayı takip eder:
Ana Sayfa, Kurumsal, İnşaat, Projeler, Gayrimenkul, İletişim.

## Yerelde görüntüleme
`index.html` dosyasını tarayıcıda açabilirsiniz.

## Vercel'e yayınlama
1. Bu klasördeki dosyaları bir GitHub deposuna yükleyin.
2. https://vercel.com adresinde GitHub hesabınızı bağlayın.
3. Add New → Project ile depoyu seçin.
4. Framework Preset: Other; Build Command ve Output Directory boş bırakılabilir.
5. Deploy'a basın.

## Yayına almadan önce
- Demo amaçlı Unsplash fotoğraflarını gerçek firma/proje görselleriyle değiştirin.
- Telefon, e-posta, adres ve sosyal medya bağlantılarını ekleyin.
- İletişim formu şu an yalnızca demo bildirimi gösterir; gerçek mesaj gönderimi yapmaz. Formspree, Web3Forms veya özel bir API ile bağlanmalıdır.
- Proje ve gayrimenkul kartları, gerçek portföy bilgileri gelene kadar bilerek temsili/placeholder olarak bırakılmıştır.
- Dış görseller ve Google Fonts internet bağlantısı gerektirir.
